# 30 Days of Deep Learning

A 30-day hands-on journey to learn **Deep Learning with PyTorch**.

## 🎯 Goal

Build a strong practical foundation in Deep Learning by learning concepts, implementing them in PyTorch, and working on small projects throughout the 30 days.

## 🛠️ Tech Stack

* Python
* PyTorch
* NumPy
* Pandas
* Matplotlib
* Jupyter Notebook

## 📚 Topics

This repository will cover:

* PyTorch fundamentals
* Tensors and operations
* Neural networks
* Training & evaluation
* Computer Vision
* CNNs
* Transfer Learning
* NLP
* RNNs / LSTMs
* Attention & Transformers
* Practical Deep Learning projects
